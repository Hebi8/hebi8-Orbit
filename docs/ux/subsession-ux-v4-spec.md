## 一、总览 Home、左侧栏与已归档页

## 二、全站统一 `Composer` 与 Lody 风格单一微标

### 1. 全站输入区底栏统一顺序（桌面 + 移动端）
全站所有输入区（新建线程、主会话、分屏子会话抽屉、完整子会话页、Hebi8、普通文件夹会话、Source Review 右栏与移动端）底栏统一采用同一左对齐控件顺序：

```text
[🔗 引用] · [Agent] · [Model] · [Effort] · [权限图标]       [○ 百分比微标] [发送/停止]
```

- **权限模式纯图标紧贴 `Effort` 右侧**：整体靠左贴齐，既不放最左也不甩到发送键旁。
  - 普通模式（`Ask` / `Auto` / `Plan`）使用不同**灰色几何图标**区分；
  - 高放权模式（`YOLO` / `Full`）使用**琥珀黄警示图标**；
  - 点击展开菜单时展示完整模式名称与说明。
- **空输入真实禁用态**：空闲且无文本/附件/待发批注时，发送键为真实 `disabled` 状态（不可误触）。

### 2. Lody 风格单一圆环 + 百分比微标
- 将原分散的上下文与额度指示合并为发送键左侧的**单一 `14px` 细圆环 + 百分比微标按钮**：
  - **新建线程页**：默认显示 **Agent 额度**（如 `86%`）；
  - **活跃会话 / 子会话 / Hebi8**：默认显示 **当前对话上下文占用**（如 `38%`）；
  - 低余量 / 高占用时转为琥珀色提示。
- **点击向上弹出统一详情浮层**（不被父容器裁切）：同屏清晰展示当前对话上下文（token 占用/上限；新建态为 `0 / 上限 · 新会话`）以及 `5 小时 / 7 天` 各自 Agent 额度与重置时间。

### 3. 分屏主/子 `Composer` 严格等高与同构红线
- 主对话与右侧子会话分屏抽屉**必须复用同一 `Composer` 组件、背景/边框 Token 层级（`var(--bg)` 底座 + `var(--panel)` 输入盒）、placeholder 规则与纯图标发送/停止/入队按钮**，绝不为主/子对话各造一套异构外观。
- 左右并列分屏时，两侧底部输入区必须**严格等高、顶线水平齐平（`Δtop = 0px`、`Δheight = 0px`）**，中间可拖拽分隔条底部补齐 **`1px` 连续顶线**，左右底栏构成一条完整连续的基准线；抽屉较窄时仅对长标签做单行溢出省略（`text-overflow: ellipsis`），绝不折行撑高。

### 2. IDE 下拉菜单（原位铅笔编辑 SSH 别名）

### 3. 普通文件夹变更条
- 宽度拉至与会话正文**完全同宽（`100%`）**。
- 改为**通透无灰底填充 + 细边框 + 中性左轨**，与用户输入气泡观感彻底拉开，不撞色。

### 4. Source Review 审阅浮层
- 支持 **`统一 / 分栏`（Unified / Split）** Diff 切换（分栏模式完整保留批注范围高亮），顶栏提供 `IDE` 直拉入口。
- **`Checkpoint` 支持发送前撤销**：在发送消息前再次点击顶栏 `Checkpoint` 按钮可撤销本次 Checkpoint（恢复至上一次快照）；发送消息后即正式确认。
- **右侧会话栏关闭键改 `×`**：取消语义模糊的「全屏会话」按钮，改为直观的 `×` 关闭图标，点击直接退出分栏返回全宽会话。
- **行内批注全宽自适应**：代码区行内 Review 评论卡片与回复输入框适应代码区全宽（取消左侧大缩进）。

### 5. 全站单块过程折叠与历史正文永不隐藏（参考 Lody）
- **单轮单一折叠块**：全站（桌面端各会话、子会话抽屉、完整子会话页、Hebi8 及移动端）单轮内的全部思考过程与工具调用步骤收拢为单一 **`过程 · 思考与 N 步调用`** 折叠块，不再拆成多个零散折叠条刷屏。
- **多轮正文永久可见**：多轮对话中每一轮的正式正文回复**永久直接保留可见**，发起下一轮对话绝不把前文折起或隐藏。

## 五、一等子会话最终规范（v4）

### 1. 左侧栏方案 A 固化 + 展开稳定性 + 条件状态穿透
- **方案 A 视觉骨架**：保持 248px（窄窗 220px）侧栏呼吸感，彻底废除 `[↳ N]` 粗胶囊与彩色圆点；父行左侧留白槽内放极淡 `› / ⌄` 轻箭头（悬停、展开或子会话活跃时显现），**0px 挤占父标题宽度**；展开子行仅保留 `1px` 细竖线 + `26px` 紧凑纯标题 + 行尾单槽 `StatusMark`。
- **展开稳定性铁律（防列表跳位）**：
  - 进入完整子会话页时，侧栏自动展开其父会话分支；
  - 随后切换到其他会话时，**绝不自动折叠**已展开的子树（防止侧栏会话行上下 Y 坐标位移跳动导致误点与视觉不适）。
- **状态穿透按折叠态严格区分**：
  - **父树折叠时**：子会话最高优先级状态（`failed > approval > running > ready > resting`）向下穿透汇总到父行尾 `StatusMark`；
  - **父树已展开时**：父行尾仅显示**父会话自身状态**，不再重复穿透子会话的审批或异常微标（子行自身已清晰呈现，避免视觉重复）。

### 2. 单层子会话边界（禁止孙会话，最大层级 = 1）
- 子会话**严禁继续向下派生孙会话**（树深上限锁定为 1 层）。
- 子会话仅支持在**同级子会话之间协作与通信**；抽屉与时间线不再保留任何孙会话面包屑或向下派发入口。

### 3. 精简入口与分屏 / 完整页收口
- **删除父会话顶栏子会话下拉入口**及常驻厚横条 `SubsessionStrip`；统一通过侧栏方案 A 与时间线内的通信轨打开分屏或进入子会话。
- **右侧无遮罩可拖拽分屏抽屉（`340–680px`）**：
  - 单行 **`40px` 顶栏**：左侧为自绘轻标题下拉切换同级子会话（**严禁原生 `<select>`**）；右侧采用直观的 **`Maximize2` 放大图标**（进入完整子会话页）与 `×` 关闭图标；
  - 内含完整子会话对话流、内联审批放行卡片、同构等高 `Composer`（追问 / `⌘↵` 实时打断 / 停止 / 切配置），且与 `Source Review` 切换互不丢失状态。
- **完整子会话页**：
  - `父会话 / 子会话` 直接融进 `PageHeader` 第一行单行面包屑（**严禁叠层 `.parent-crumb-bar`**）；
  - **删除顶栏多余的「分屏」返回按钮**（用户可直接经左侧导航树或顶部面包屑返回主会话）。

### 4. 统一跨会话通信极简方向语言
- 彻底删除「同级会话通信」「跨线程同步」「来自子会话」「已回传摘要」等冗余说明文字与徽标。
- 全站普通会话间的派发、同级协作与子会话回传（`child_result`）统一为同源低刺激细轨：
  - **发出（派发 / 外发消息）**：**`1.5px` 中性灰左轨 + `↗` 外发轻图标** + 目标标题 + 行尾单槽 `StatusMark`（整批均静息时自然收合）；
  - **收到（回传 / `child_result` / 接收消息）**：**`1.5px` 低饱和淡强调左轨 + `↵` 回折轻图标** + 一行摘要（默认折叠，点击展开干净格式化 Markdown，**严禁裸吐 `<pre>` 系统唤醒词**）。
- 底层原生 subagent / swarm 成员仅在元信息末标注极淡纯文本「内置」，抽屉内给单行静默提示条。

## 六、Hebi8 / PA 最终规范

### 1. 暂不挂子会话，保留跨目录跳转提示卡片
- **PA 暂不挂子会话**：删除 Hebi8 / PA 顶栏子会话入口、PA 下挂子会话以及 PA 子会话分屏抽屉。
- **保留专属跨目录跳转提示卡片**：Hebi8 对话流内保留独立的跨目录会话跳转提示卡片（展示状态微标、项目·机器标签与说明正文，点击直达对应目录会话），不与普通父/子会话的极简 `↗ / ↵` 细轨强行同化。

### 2. 顶栏与「快速汇总」位置收敛
- **顶栏右上单一树形图标**：删除显眼的「折叠树」「折叠换代」文字按钮与「快速汇总」按钮，顶栏右上仅保留**单一克制的树形图标**用于打开/关闭上下文节点树。
- **按需「快速汇总」建议提示条**：移至底部输入框正上方作为轻量按需提示条——动态统计未读顶层会话数（或在较长时间无活动时出现），点击默认填充提示词至输入框（支持直接发送或点 `×` 关闭），**未读数归零时自动隐藏**。

### 3. 纵向 Git-Tree 上下文节点树
- **标准 `git log --graph` 方向**：**`HEAD · 当前活跃段` 固定置顶，沿左侧主干轨道线越往下越旧**。
- **默认全部折叠**：所有历史合并节点打开节点树时**默认全部折叠**。
- **极简节点行**：彻底移除节点顶行冗余的「置顶」徽标与内部节点 ID（仅保留干净的类型标签与段/轮计数）；彻底移除节点树面板底部无意义的操作提示文字。
- **两类交互清晰分离**：
  - 点击折叠节点旁专门的**展开图标 `› / ⌄`**，沿分支线展开/收起下层原始片段；
  - 点击**节点本体**，在下方弹出可关闭（`×`）的节点详情面板。
- **手动折叠收进面板顶部**：手动「折叠当前段」动作收进节点树面板顶部，且执行折叠后 `HEAD` 轮数归零，防止连续空折。

## 七、项目设置与网络容灾规范

### 1. 项目设置与 Codex 风格目录选择器
- **去掉冗余默认策略**：删除项目设置顶部的默认目录隔离策略切换，仅保留新建线程页的 **`Worktree`** 开关。

- **Codex 风格统一目录选择器**（`+ 添加组成部分` 与「浏览他机目录 / 选择设备目录」共用）：

  - 下方为清爽的上下目录列表，保证鼠标点选、双击进入子目录与键盘导航（`↑↓ / Enter / Backspace`）的选中路径结果 **100% 一致**。

### 2. 网络与机器管理、故障接管与左下直连状态
- **机器列表去噪**：移除主机顺位列表左侧多余的排序号数字与拖拽排序图标。
- **受限节点（`worker`）完整可管理**：点击任意受限节点（含新配对节点）均可在原位正常展开管理面板（展示工作范围说明与可编辑目录白名单；新配对受限节点分配唯一 ID 并自动展开，不触发页面滚回顶部）。
- **故障接管横幅可关闭**：顶栏故障接管提示条右侧增加 **`×` 关闭按钮**（读完即可关闭，左下角连接态仍常驻提示；移动端同步）。
- **左下角直连本机图标化**：当本机直连本地节点时，去掉「直连」文字，改用简洁的**直连本机图标**（悬停提示「直连本机」）。
